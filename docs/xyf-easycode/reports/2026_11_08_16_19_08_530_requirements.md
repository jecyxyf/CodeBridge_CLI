# CodeBridge 需求变更记录：两端静态编译内嵌 Mutagen

## 1. 变更背景与范围

- **项目**: CodeBridge CLI (`0.0.1`)
- **记录标识**: `2026_11_08_16_19_08_530_requirements`
- **架构文件**: `docs/xyf-easycode/html/software_architecture.js`
- **核心变更**: 严格规范 `CodeBridgeLocal` 与 `CodeBridgeVPS` 两端主程序必须在构建期静态编译内嵌各自所需的 Mutagen 组件，交付为独立纯绿色单文件。用户直接运行，运行期严禁再次下载、拉取或编译 Mutagen 及其源码。

## 2. 需求调整清单

| 需求项 | 原始定义 | 调整后约定 | 涉及模块 |
|---|---|---|---|
| **Local 静态打包** | 仅抽象提及单文件交付，未锁定静态内嵌与自解压路径 | 构建期用 Go 编译 `depends/mutagen`，Rust 编译期通过 `include_bytes!` 静态内嵌 `mutagen` 主程序及 `mutagen-agents.tar.gz` 包；运行期自动在私有运行目录解压，零外部依赖 | `module-codebridge-local` |
| **VPS 静态打包** | 默认由 Local 上传 Agent，VPS 程序未包含 Agent 组件 | 构建期将 Linux 版 `mutagen-agent` 静态内嵌进 `CodeBridgeVPS`；启动时直接在本地私有目录释放就绪，不再现场下载或依赖临时网络传输 | `module-codebridge-vps` |
| **构建链条闭环** | `build.sh` 仅含 `cargo build` | `build.sh` 扩展为两阶段构建：先由 Go 构建 Mutagen 产物，再由 Cargo 完成静态资源内嵌打包 | 构建与分发脚本 (`build.sh`) |
| **未知项收敛** | 存在“内嵌组件释放目录、多实例隔离未定”等阻塞项 | 确认释放到程序所在目录的私有运行目录或用户缓存目录，关闭对应 unknowns 疑问 | `module-codebridge-local` |

## 3. 架构校验结论

- **格式校验**: `ProjectFile.parse` 与 `Model.validate` 严格通过（0 errors, 0 warnings）。
- **布局锁定**: 所有模块与分组的坐标、尺寸、样式、连线端口、现有结构体与接口签名保持不变。
