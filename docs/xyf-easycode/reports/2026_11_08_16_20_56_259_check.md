## 3. 审查建议与后续行动

当前差异属于架构更新后的正常现状。后续应按以下步骤组织开发工作：
1. **重构 `build.sh`**：利用已就绪的 Go 环境，编写编译 Mutagen 主程序与 Agent 的自动化流程。
2. **改造 Rust 业务主程序**：
   - 在 `src/Local/main.rs` 中通过 `include_bytes!` 引入 Windows 版 `mutagen.exe` 和 `agents` 资源包，增加自解压模块与真实命令调用。
   - 在 `src/VPS/main.rs` 中通过 `include_bytes!` 引入 Linux 版 `mutagen-agent`，完善本地 Agent 准备、跨进程台账锁与真实 TCP 探测。
3. **改造测试用例**：让测试真实触发自解压与本地回路会话，验证真实的同步与端口转发。
