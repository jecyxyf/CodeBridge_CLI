# CodeBridge 端到端全链路真实联调测试方案

## 1. 测试目标与核心场景

解决“本地工程包含硬件驱动必须在本地运行，同时需要调用远端 VPS 上的 AI Agent 开发代码并操控网页调试”的问题。

本次测试通过真实的本机环境与韩国云端 VPS（`<VPS_IP>`），验证 CodeBridge 的 4 大核心能力：
1. **纯绿色单文件交付**：两端分别仅拷入一个程序，无需装 Go 或 Mutagen；
2. **跨国毫秒级代码双向同步**：两端文件增量同步，互不延迟；
3. **本地网页反向穿透**：远端 VPS 能够直接操控本地带硬件驱动的网页服务；
4. **动态热插拔端口与安全退出**：不中断既有任务加开端口，退出时干净利落不残留。

## 4. 手动快速执行指引

如果您希望手动一步步感受连接过程，可直接在终端依序粘贴以下命令：

```bash
# 1. 把服务端可执行程序推送给 VPS 并启动
scp bin/VPS/CodeBridgeVPS root@<VPS_IP>:/root/CodeBridgeVPS
ssh root@<VPS_IP> "chmod +x /root/CodeBridgeVPS && /root/CodeBridgeVPS start"

# 2. 本地进入任意项目目录，发起桥接
cd /home/xyf/orca/CodeBridge_CLI/0.0.1
CodeBridgeLocal start --vps-ip <VPS_IP> --web-port 3000

# 3. 检查当前连接与同步状态
CodeBridgeLocal status

# 4. 测试完毕后一键安全退出
CodeBridgeLocal stop
ssh root@<VPS_IP> "/root/CodeBridgeVPS stop"
```

## 5. 异常情况排查与回滚

若在测试中遇到网络意外中断或异常退出：
- **清理 Mutagen 本地残留**：`mutagen sync terminate --all`、`mutagen forward terminate --all`
- **清理 VPS 端口残留**：`ssh root@<VPS_IP> "killall mutagen-agent CodeBridgeVPS 2>/dev/null || true"`
