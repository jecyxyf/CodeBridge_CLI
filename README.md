# CodeBridge CLI

## 1 项目描述

- **核心依赖**：本项目底层依赖开源项目 [Mutagen](https://github.com/mutagen-io/mutagen)，用于实现高效稳定的跨平台文件实时双向同步与网络端口反向转发。
- **工作原理**：
  - 远程运行 `CodeBridgeVPS`，本地运行 `CodeBridgeLocal`，借助 Mutagen 实现两端目录实时毫秒级同步。
  - 本地通过 SSH 连接 VPS 调起 AI Agent 开发代码；本地启动 Web 服务，远端通过反向映射端口直接访问网页进行功能联调。
- **两大核心优势**：
  1. **极致安全隔离**：Agent 只能访问绑定的单个目录，无法获取本地任何软硬件信息与磁盘隐私，极大保障本地与账号安全。
  2. **一主多从并行开发**：一台 VPS 可供多台本地主机同时连接，原子防冲突，并行开发多个独立项目。
- **目录隔离规范**：
  - 一台主机仅允许绑定一个专属目录；单机多项目须在专属目录下建子目录；不同主机严禁共用同一目录。
- **VPS 选型建议**：
  - 建议选用**带有住宅 IP 的 VPS** 配套本项目使用，能大幅降低 AI 平台账号与网页风控拦截风险，保障 Agent 编程与服务调试顺畅稳定。

## 2 快速开始

- **2.1 一键安装VPS**：使用 `/codebridge_vps_install` 提供登录信息，全自动打通免密并安装程序与技能。
- **2.2 VPS启动**：使用 `/codebridge_vps 启动当前服务`，云端待命并初始化台账。
- **2.3 本地启动同步**：使用 `/codebridge_local 把当前项目连到 VPS，开启双向同步并反向映射 3000 端口`，打通实时代码同步。
- **2.4 SSH连接开发**：免密 `ssh root@<VPS_IP>` 进入同步目录，调起 AI Agent 编写代码，代码秒级同步回本地。
- **2.5 Web功能调试**：本地启动 Web 服务，远端即可通过映射端口直接打开网页进行功能调试。

## 3 提示词功能说明

全部操作均通过 `/技能名称 + 需求` 对话完成：

| 模块 | 操作 | 示例提示词（直接复制发送） | 执行效果 |
| :--- | :--- | :--- | :--- |
| **VPS初始化** | **一键安装** | `/codebridge_vps_install 这是我的 VPS 登录信息（IP: xxx，用户名: root，密码: xxx，安装目录: ~/codebridge），帮我全自动安装好` | 自动测试网络、造钥匙打通免密、部署程序技能并就绪待命。 |
| **云端 (VPS)** | **启动服务** | `/codebridge_vps 启动当前服务` | 启动待命服务与独占台账。 |
| **云端 (VPS)** | **查询状态** | `/codebridge_vps 查询当前状态` | 探测端口连通性并输出状态表格。 |
| **云端 (VPS)** | **停止服务** | `/codebridge_vps 停止当前服务` | 安全关停服务并释放端口，保留代码。 |
| **本地 (Local)**| **启动桥接** | `/codebridge_local 把当前项目连到 VPS，开启双向同步并反向映射 3000 端口` | 建立双向秒级同步与反向网页穿透。 |
| **本地 (Local)**| **查询状态** | `/codebridge_local 查询服务状态` | 查看连接状态、同步进度与调试地址。 |
| **本地 (Local)**| **追加端口** | `/codebridge_local 追加一个新的映射端口` | 动态加开端口，不打断现有同步。 |
| **本地 (Local)**| **停止断开** | `/codebridge_local 停止当前的服务` | 安全断开桥接，代码完好保留。 |
