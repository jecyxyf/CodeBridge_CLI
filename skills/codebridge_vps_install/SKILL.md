# CodeBridge VPS 开箱全自动安装技能

作为 CodeBridge 专属安装专员，负责为用户提供极致无感的云端安装体验：用户只需提供或确认 VPS 登录信息，剩下的全部底层配置与安装工作由本技能全自动包办。

## 适用场景

新购置或初次接入一台远程 VPS 时调用本技能，一次性完成两端免密修路、服务端部署与初始化。

## 全自动执行流水线

### 1. 要素完整性检查与主动确认规范
- **关键要素核查清单**：
  1. **VPS IP 地址**（必填）：若未提供，**必须停下来主动询问**：“请提供您的 VPS 公网 IP 地址”；
  2. **登录密码**（未免密前必填）：若检测到未免密且未提供密码，**必须主动询问**：“请提供一次 SSH 密码，用于为您全自动打通免密连接”；
  3. **用户名**（可选）：缺省自动使用 `root`；
  4. **SSH 端口**（可选）：缺省自动使用 `22`；
  5. **安装目录**（可选）：缺省自动使用 `~/codebridge`。
- **缺失与确认处理机制**：
  - 缺失必填项时：绝不盲目瞎猜，以极简大白话向用户提问补齐缺失项；
  - 要素齐备后：向用户展示简短的**信息核对看板**（标明生效的 IP、用户名、端口与安装目录），并立即启动后台自动化流水线。

### 2. 网络探测与本地公钥准备
- 探测远端 VPS 对应端口的基础网络连通性；
- 检查本地电脑 `~/.ssh/` 是否已存在公钥；若无，自动静默执行 `ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519` 生成专属密钥对。

### 3. 配置保存与自动打通免密
- 将连接信息规范保存至项目根目录 `vps_ssh.config`，并在本地 `~/.ssh/config` 配置快捷主机别名；
- 自动利用密码静默登录远端，将本地公钥写入云端 `~/.ssh/authorized_keys`，实现永久免密；
- 执行免密连通性握手验证，确保后续一切操作均无需再输密码。

### 4. 部署服务端程序与技能并激活
- 自动在远端 VPS 创建目标安装目录（如 `mkdir -p <安装目录>`）；
- 自动定位本地编译好的绿色单文件 `bin/VPS/CodeBridgeVPS` 及 `bin/VPS/skills`；
- 走打通的免密通道将程序及技能完整推送至远端目标安装目录；
- 远程执行 `chmod +x <安装目录>/CodeBridgeVPS` 赋予权限，运行 `--version` 自检，并执行 `<安装目录>/CodeBridgeVPS start` 启动待命服务与初始化台账。

### 5. 交付与看板呈现
使用简洁的 Markdown 表格向用户汇报各环节结果（免密状态、安装目录、程序路径、待命服务名），并告知用户现在即可在本地随时输入 `/codebridge_local ...` 开展协同开发。
