# CodeBridge 本地客户端管理技能

作为 CodeBridge 本地连接管理员，负责调度和管理 `CodeBridgeLocal` 客户端程序，打通本地硬件工程与远端云服务器的实时协同通道。

## 适用场景

当用户需要在本地电脑上与远端 VPS 建立连接、启动代码同步、把本地带硬件驱动的网页服务反向穿透到云端、追加映射端口或查询连接进度时调用本技能。

## 执行流程与规范

### 1. 定位执行程序
优先在项目根目录 `bin/Local/CodeBridgeLocal` 查找可执行程序；若不存在则使用系统全局命令 `CodeBridgeLocal`。若均不存在，提示用户先执行 `./build.sh`。

### 2. 智能参数推导与调度
- **启动桥接 (`start`)**：
  - 用户未显式提供 `--vps-ip` 时，优先从项目根目录的 `vps_ssh.config` 或 `~/.ssh/config` 提取有效主机地址；
  - 网页端口 `--web-port` 缺省默认为 3000；
  - 遵循“显式输入 > 历史保存配置 > 默认值”的合并原则，支持全零参数自动续连。
- **查询状态 (`status`)**：默认检查当前目录项目的连接状况、文件同步状态（watching/syncing/conflicted）与云端访问网址。
- **动态加端口 (`forward`)**：
  - 用户显式指定端口（如 8080）时，直接执行 `forward --web-port <端口>`；
  - 若用户未指定端口号，Agent 自动检测本地正在运行的常用 Web 端口（如 8080/5173/8000）供用户确认，或主动提示输入端口；增补过程不中断既有文件同步通道。
- **安全停止 (`stop`)**：
  - 默认安全停止当前项目的同步与端口映射；
  - 用户表示“全部关停”或“断开所有”时，执行 `stop --all`，彻底释放端口并保留全部代码。

### 3. 结果呈现与输出
解析命令返回的统一标准 JSON，必须使用 Markdown 表格向用户汇报业务状态，包含：连接状态、项目目录、本地端口、VPS 映射端口及云端调试网址。

### 4. 常见故障诊断
- **SSH 认证失败**：提示检查公钥是否写入远端 `~/.ssh/authorized_keys` 或主机名是否匹配；
- **同步停滞**：指导用户通过 `status` 查看是否有文件冲突（conflicted），避免盲目删除工程文件。
