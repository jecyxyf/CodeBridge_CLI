# 架构名称翻译

## 输入与输出

- 输入：架构 JSON、需要翻译的中文名称，以及模块、对象种类或稳定 ID 等定位信息。
- 输出：只更新目标英文名称及模型要求的来源状态的架构 JSON，附中文名到英文名的变化清单。
- 本技能目录的上两级是技能包根目录。

字段、更新函数和校验以 [数据模型](../../tools/html/assets/model.js) 为准。命名格式可复用 [translation.js](../../tools/html/assets/translation.js) 的纯格式化函数；本技能的语义翻译由当前 Agent 完成，不要求启动额外 Agent 或注册翻译服务。

默认读取和更新 tools/archify.json；用户指定其他架构文件时使用其指定文件。

## 定位目标

| 对象 | 数据位置 |
|---|---|
| 模块参数或属性 | modules[].parameters[] |
| 数据结构字段 | modules[].structures[].fields[] |
| 方法 | modules[].interfaces[] |
| 方法输入、输出参数 | modules[].interfaces[].inputs[] / outputs[] |
| 消息携带参数 | modules[].events[].parameters[] |

中文名称重复时，用模块、种类和 ID 缩小范围；仍有多个候选就列出让用户选择，不擅自把同名对象全部改掉。只处理用户指定的对象。

## 翻译和命名

1. 读取并检查输入 JSON，定位目标。结合所属模块、用途、类型和已有术语理解名称，保持同一术语的翻译一致。
2. 用户或目标代码已有明确命名约定时沿用；未指定时，变量、参数、字段和方法采用 camelCase。名称应是可用的英文标识，不包含中文、空格或括号签名。
3. 默认 camelCase 可导入 tools/html/assets/translation.js，然后调用 EasyCode.Translation.formatName(englishText, 'parameter')。该函数仅整理命名格式，不执行语义翻译；不要把中文原文当作英文结果。其他命名约定按已确认规则处理，不强套该函数。
4. 列出中文名、原英文名、新英文名及对象位置，按项目的确认规则处理覆盖已有值的写入；已明确授权的范围不重复申请。
5. 更新目标 englishName，中文名、说明、类型、默认值、稳定 ID 和布局保持不变。使用模型语义更新函数；必要时只有相关的来源状态从 verified 变为 modified。
6. 检查同一作用域的名称，避免意外重名；合法重载遵循目标语言和项目约定。运行模型校验，再检查差异只落在目标英文名及必要状态上。
7. 保存前检查文件是否出现并发修改，写入后读回核对。

例如，指定方法“保存任务”可得到 saveTask；指定参数“任务编号”可得到 taskId。最终名称由上下文和项目约定确定，不提供随机同义词抽取。

## 交付与边界

报告变更清单、JSON 路径和检查结果。只有总任务要求同步网页时，才把输出交给 archify2html。不要顺带翻译全部名称、改动实际源码或调用网页中的在线翻译按钮。
