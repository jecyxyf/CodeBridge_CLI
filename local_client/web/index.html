首次连接这台服务器

请确认这是你想连接的服务器。信任后，CodeBridge 会在这台电脑上记住它，下次自动核对，无需你记住指纹。

服务器地址与端口

服务器身份尚未通过独立渠道验证。地址正确也不代表身份已确认；只有你信任这台服务器时，才继续连接。确认后将向它发送 SSH 登录密码。

高级详情：服务器指纹

指纹用于识别服务器。你可以通过可信渠道请管理员核对，不需要记住它。

删除这台服务器的指纹？

仅删除 CodeBridge 在这台电脑上记住的以下服务器身份，不会修改服务器、登录密码或其他服务器的记录。

服务器地址与端口

适用于你已确认服务器重装或主机密钥更换的情况，不能解决密码错误或网络问题。删除后，下次连接需要重新确认信任；请勿用它绕过不明原因的身份变化警告。
